
# 🏆 OpenRank

> **Contribute. Build your profile. Get recognized.**

OpenRank is a beginner-friendly open-source project where anyone can make contributions, build a public contributor profile, earn achievements, and appear on the community leaderboard.

**No previous open-source experience required.**

---

## 🚀 Make Your First Contribution

You can join OpenRank in a few minutes.

### 1. Fork this repository

Click the **Fork** button at the top of this repository.

### 2. Create your profile

Inside the `contributors/` directory, create:

```text
your-github-username.yml
```

For example:

```text
contributors/ashishsinghbora.yml
```

### 3. Copy the template

Open:

```text
contributors/_template.yml
```

Copy its contents into your new file.

### 4. Add your information

Example:

```yaml
username: ashishsinghbora
name: Ashish Singh Bora
bio: Computer Science student interested in AI and systems
skills:
  - Python
  - Linux
  - Machine Learning
```

### 5. Commit your changes

Create a commit such as:

```text
feat: add ashishsinghbora profile
```

### 6. Open a Pull Request

Open a Pull Request from your fork to this repository.

GitHub Actions will automatically validate your profile.

### 7. Get recognized 🎉

After your contribution is merged, your profile will become part of OpenRank.

Your contribution can earn:

* ⭐ Contribution points
* 🏅 Achievements
* 📈 Leaderboard position
* 🌱 Contributor level

# 🛠️ Technology

OpenRank currently uses:

* Python
* GitHub Actions
* YAML
* GitHub API
* Markdown

There is intentionally no database or web application in V1.
